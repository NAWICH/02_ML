# 🧠 Day 17: Lok Sewa Question Subject Classifier
### Neural Network built with PyTorch

A deep learning classifier that predicts the subject of a Lok Sewa exam question.
Built from scratch using PyTorch as part of a 30-day AI Engineering journey.

---

## What It Does

```
Input:  "What is the capital of Nepal?"
Output: { "subject": "GK", "confidence": 0.94 }

Input:  "Calculate 15% of 200"
Output: { "subject": "Math", "confidence": 0.98 }
```

---

## How It Works

```
Question Text
     ↓
HuggingFace Embeddings
(text → 384 numbers)
     ↓
Neural Network
Layer 1: 384 → 256 (ReLU)
Layer 2: 256 → 128 (ReLU)
Layer 3: 128 →   5 (Softmax)
     ↓
Subject Probabilities
[GK: 0.94, Math: 0.02, Nepali: 0.02, English: 0.01, Science: 0.01]
     ↓
Predicted: GK (94% confident)
```

## Model Architecture

```python
Input (384)
    │
Linear(384 → 256) + BatchNorm + ReLU + Dropout(0.3)
    │
Linear(256 → 128) + BatchNorm + ReLU + Dropout(0.3)
    │
Linear(128 → 5)
    │
Output (5 subject probabilities)
```

**Total parameters:** 132,869

## ⚠️ Known Limitations

### 1. Small Dataset
```
192 total samples (~38 per subject) is insufficient
for a production-ready classifier.

Minimum recommended: 1,000+ samples per subject
```

### 2. Data Leakage
```
Training and test data both generated by the same LLM
(Day 16 question service). They share the same writing
style, vocabulary, and sentence patterns.

100% test accuracy reflects the model recognizing
LLM writing patterns, not true subject understanding.
```

### 3. Overfitting
```
Model reached 100% by Epoch 3.
Real learning should take longer.
Fast convergence on small data = memorization.

Evidence:
- Epoch 10: Loss jumped from 0.0845 → 0.1759
- Loss instability after Epoch 6
- These jumps indicate memorization, not stable learning
```

### 4. No Real-World Validation
```
Model has not been tested on:
- Actual PSC past paper questions
- Questions written in Nepali
- Questions from human-written sources
- Questions outside the training distribution
```

## What I Learned

### Technical
- How to build a neural network in PyTorch from scratch
- What tensors are and how they flow through layers
- What loss measures and how gradient descent reduces it
- What overfitting looks like in training metrics
- How to save and load model weights

### Critical Thinking
- **100% accuracy is suspicious, not celebratory**
- Perfect test results on small datasets = memorization
- Test data must be truly independent from training data
- Synthetic training data has real limitations in production
- Dataset size and diversity matter more than model complexity

### Key Insight
```
The model learned:
"What writing style does an LLM use for GK questions?"

The model did NOT learn:
"What makes a question about General Knowledge?"

These are very different things.
```

## What Would Make This Better

### Better Data
```
Current:  192 LLM-generated questions
Better:   1,000+ questions from:
          - PSC official past papers (psc.gov.np)
          - Human-written prep books
          - Questions in Nepali and English
          - Multiple difficulty levels
          - Questions from different years
```

### True Validation
```
Current:  Test on LLM-generated questions
Better:   Test on 50 real PSC questions
          labeled manually before running model
```

### Better Training
```
Current:  30 epochs on 192 samples
Better:   Early stopping (stop when test loss increases)
          Learning rate scheduler (reduce LR over time)
          Data augmentation (paraphrase questions)
```
